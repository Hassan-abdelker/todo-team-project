# Projet Todo Team

## Description
Application web simple pour gérer une liste de tâches en équipe.  
Projet réalisé dans le cadre du TP Terminale.

## Technologies utilisées
- HTML
- CSS
- JavaScript
- Git & GitHub

## Installation
1. Cloner le dépôt :  
   `git clone https://github.com/Hassan-abdelker/todo-team-project.git`
2. Ouvrir `index.html` dans un navigateur.
